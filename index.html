习题 1.1 · 元件功率与参考方向

图 1-20 的 5 个元件，电压、电流均为关联参考方向，数值带符号直接代入 P = U * I（数据已按练习本解法核对：U = 140、-90、60、-80、30 V，I = -4、6、10、-4、6 A）。P 为正 = 吸收功率（负载）；P 为负 = 实际发出功率（电源）。最后验算功率平衡：发出合计 560 + 540 = 1100 W，吸收合计 600 + 320 + 180 = 1100 W，两边相等，符合能量守恒。关联参考方向（电流从电压正极流入）时吸收功率 P = U * I；非关联时吸收功率 P = -U * I，本题 5 个元件都是关联方向。

基础工具 · 欧姆定律与功率

U = I * R；P = U * I = I * I * R = U * U / R。三个量填任意两个，留空的那个会被算出来。

基础工具 · 串联等效与分压

R = R1 + R2 + R3；电流处处相等；分压 U1 = U * R1 / (R1 + R2 + R3)。图由计算结果生成。

基础工具 · 并联等效与分流

1 / R = 1 / R1 + 1 / R2 + 1 / R3；各支路电压相等；两支路分流 I1 = I * R2 / (R1 + R2)、I2 = I * R1 / (R1 + R2)（分流与电阻成反比），三支路时各支路电流 = U / 该支路电阻。图由计算结果生成。

基础工具 · 额定功率限流

电阻额定功率 P 不能超：Imax = 根号(P / R)，Umax = 根号(P * R)。

基础工具 · 电位计算（双电源串联模板）

模板电路：E1 经 R1、R2 与 E2 串联成回路，中间点为 A，下端接参考点（电位 0）。先求回路电流 I = (E1 - E2) / (R1 + R2)，再由 A 点沿 R2 往下走到参考点求 VA。

习题 2.1 · 开关两种状态的等效电阻 Rab

基础工具 · 复数互换与瞬时值（补充题）

代数式 a + jb 与极坐标式 模∠角 互换；相量（有效值）转瞬时值：幅值 = 有效值 * 1.414，u(t) = Um * sin(ωt + φ)。例题就是补充题原题：U 点 = 220∠30° V，I 点 = -4 - j3 A。

基础工具 · 相量图与正弦波形（U、I 分开画）

把电压、电流相量填进来：U 和 I 各画一张相量图、各自比例尺（220 V 和 5 A 不再共用一把尺）；波形图上下两栏，每栏按自己的幅值归一化，谁也不会被压扁。数值标注在各图下方的图例行里。

基础工具 · 单元件交流（R / L / C）

电阻：电压电流同相。电感：XL = 2 * π * f * L，电压超前电流 90°。电容：XC = 1 / (2 * π * f * C)，电流超前电压 90°。填电流求电压，或填电压求电流（二选一）。

习题 3.5 / 3.6 · 单电容与单电感

纯电抗元件的固定套路：先算容抗 XC = 1 / (2 * π * f * C) 或感抗 XL = 2 * π * f * L，再用相量欧姆定律求另一个量，最后处理 90° 相位：电容电流超前电压 90°，电感电压超前电流 90°。已知量可以给瞬时值（幅值 + 初相）或相量（有效值 + 初相），另一个量两种表示都输出。

习题 3.15 · RLC 串联与功率

XL = 2πfL，XC = 1/(2πfC)，Z = R + j(XL - XC)，I = U / |Z|，P = I * I * R，Q = I * I * (XL - XC)，S = U * I，cosφ = R / |Z|。例题为课本 3.15。

例 8-1 三极管静态工作点

固定偏置电路估算：IB = (UCC - UBE) / RB（UBE 填 0 即忽略），IC = β * IB，UCE = UCC - IC * RC。饱和电流 ICsat = UCC / RC，若算出的 IC 大于 ICsat，说明已进入饱和区，实际 IC 取 ICsat、UCE 约 0。
