# electrical-electronics-calculator

电工电子计算陪练程序（网页版，手机优先）——《电工电子技术（第三版）》老师勾画的作业题，方法先行、逐步推导、换数再练。

- V1：直流等效 / KCL-KVL / 电位、相量换算与单元件交流、RLC 串联与功率因数、二极管稳压与三极管静态工作点
- V2：16 个陪练器（1.1、1.3、1.6、1.7、1.12、2.1、2.7、2.8、2.11(a)(b)、3.4、3.5/3.6、3.19，3.15 补齐瞬时值表达式），先选方法再计算，带单位换算、数量级 / 符号 / 回代验算和换数再练
- 1.1 已按练习本数据修正：P = -560、-540、600、320、180 W，发出 1100 W = 吸收 1100 W

使用：用浏览器打开 `index.html` 即可（单文件，离线可用；在微信 / QQ 里直接点开只是预览，请先保存到本地再用浏览器打开）。

来源：Muse 构建的静态页面导出（artifact `dian-gong-dian-zi-ji-suan`），仅供学习使用。
